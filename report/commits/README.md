# Ảnh chụp commit

Đề bài yêu cầu nộp kèm **hình chụp các lần commit** và repo phải có ít nhất 10 commit
trải đều trong các ngày.

Repo local của project đã có lịch sử commit thực tế (xem `report/git-log.txt` và
`report/commits/local-git-log.png`). Ảnh local chỉ là minh chứng tạm.
Trước khi nộp:

1. Tạo repo GitHub/Bitbucket/GitLab và push toàn bộ commit.
2. Mở trang **Commits** của repo.
3. Chụp ảnh danh sách commit (thấy rõ tên, thời gian, thứ tự) và lưu vào thư mục này,
   ví dụ `commits-github.png`.
4. Kiểm tra có **≥ 10 commit** và thời gian commit phân bố ở nhiều ngày.
5. Chạy lại `package.ps1` để đưa ảnh vào file zip.

Không nên chỉnh sửa ngày commit bằng tay để tạo lịch sử giả; hãy dùng lịch sử phát
triển thực tế của bạn.
